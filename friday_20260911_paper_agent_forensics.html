The agent worked correctly on Friday. Friday was a NO-TRADE day, not a failure.

The live loop ran for the whole session (09:10:25 → clean exit at 15:40:15). The paper agent ran on every one of the 385 minute-ticks for both symbols. It reached the 14:59 freeze at 14:59:19 (SENSEX) and 14:59:25 (NIFTY), using 14:59 data written less than half a second earlier.
