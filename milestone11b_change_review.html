Design: how the "control + 1 feature" test works

  • Every numeric candidate's threshold is a Training-only median, fixed before any Validation/Test look — same discipline as the frozen control.
  • Every candidate's sign is a documented, pre-specified a priori rationale (mirroring the control's own established PCR/imbalance/straddle signs, or classify_option_positioning's own bullish/bearish reasoning) — never fit or flipped based on which direction "worked."
  • The combined model is a plain 4-way majority vote: the control's existing 3 votes + this one candidate's vote. A genuine 2-2 tie is an honest abstention (no prediction) — never arbitrarily broken.
  • Divergence and Expiry Regime are deliberately not folded into a vote — per the spec's explicit instruction, they're reported as diagnostic splits of the control's own accuracy instead.

Most of the time these candidates produce a 2-2 tie against the control's own votes and contribute nothing. On the rare days they do resolve, the "improvement" is 3-4 SENSEX-heavy observations — exactly the "apparent pooled result driven by one symbol" failure mode the milestone brief named explicitly. A naive "accuracy > control" check would have called these 3 features promising; looking at n and the abstention/symbol pattern shows that's not credible evidence.
