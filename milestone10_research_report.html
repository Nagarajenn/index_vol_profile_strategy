Milestone 10 — Research Discovery Report
Could a 2:59 PM decision framework anticipate the 3:00–3:15 PM move and select a favorable option?

Status: Read-only research. No production code, schema, UI, or forecasting logic was modified. No new Dhan API calls were made — every number below was derived from data already captured (raw_candles, option_chain_raw, transition_actual_outcome). All analysis lives in the scratchpad only.

Sample: NIFTY + SENSEX, CAS-era trading days 2026-08-03 → 2026-09-04 (25 trading days/symbol, 50 symbol-days total; 46 symbol-days have usable 1-minute option-chain coverage in the 14:30–15:15 window).

Headline, stated plainly up front: with ~46–50 symbol-days of data, nothing in this report reaches a level of evidence that would justify an unattended trading rule. The single most useful, reproducible signal found is a modest (58.7% accuracy, N=46) options-only directional vote — better than chance, far from reliable. The honest recommendation is WAIT (accumulate more data), not BUY CE / BUY PE, as the default answer today. Full reasoning below.

Parts 3–4 — Underlying Engine & 2:59 Market-State Vector

Reused existing, unmodified analytics.vwap.compute_vwap and analytics.volume_profile.compute_volume_profile (bin size 5 for NIFTY, 25 for SENSEX — matches production convention), called at 8 checkpoints per day: 14:30/40/45/50/55/57/58/59. Computed per checkpoint: close, momentum (1/3/5/10/15-min), distance from session high/low, VWAP distance, POC/VAH/VAL + 15-min POC migration, cumulative & trailing-15-min volume share, and a range-compression ratio (last-15-min range ÷ prior-15-min range).

400 rows produced (50 symbol-days × 8 checkpoints). This is the underlying half of the "2:59 state vector" the milestone asked for — the 14:59 row of this table.

Model A (underlying-only vote: VWAP-dist + mom5 + mom15 + POC-migration)

N=50, accuracy = 0.280 — worse than chance. Combining a good feature (POC migration, 0.60) with two weak/anti-informative ones (VWAP-dist, mom5) in an unweighted vote actively hurt performance. This is a concrete demonstration that "more features in a vote" is not automatically better on this sample size.

Model B (options-only vote: PCR + Call/Put volume imbalance + straddle change)

N=46, accuracy = 0.587, UP-precision 0.52, DOWN-precision 0.67 — the best-performing model found in this milestone.

Model C (combined vote: A + B features together)

N=46, accuracy = 0.522 — worse than Model B alone. Directly answers the spec's "do not assume combining helps — show evidence": the evidence here says combining hurt, because Model A's weak features diluted Model B's real signal.

MODERATE (single-model) Model B (options-only) is the one candidate directional signal in this entire study that both beats chance and survived a naive-combination stress test. Confidence is capped at MODERATE, not STRONG, given N=46 and no out-of-sample validation beyond this one pass.

Part 18 — Option Sampling-Frequency Recommendation

Testing the user's original 8-snapshots/day hypothesis directly against the now-available 1-minute reconstruction, rather than accepting it.

Feature1-min-to-1-min noise (typical step)Staleness at 5-min samplingStaleness at single end-of-window snapshot

Nuanced answer, not accept/reject: PCR is essentially unaffected by sparser sampling — a 5-min or even single-snapshot read is nearly as good as 1-minute for this feature. IV skew and ATM straddle value are noisier and genuinely lose fidelity as sampling sparsens (staleness roughly triples from 1-min to end-of-window-only). Recommendation: the original 8-fixed-checkpoint design is adequate for PCR-driven signals but would understate the true intraday range of IV-skew/straddle-based signals — if those features end up mattering more (Part 6 suggests IV skew is the late-developing one), a denser late-window sample (e.g. every 1–2 min from 14:50–14:59) is worth the marginal cost; a full all-day 1-min capture is not shown to add value beyond that. MODERATE, N=46 symbol-days.

Parts 21–22 — Statistical Discipline & Robustness

Discipline applied throughout this report: every number carries its N. Spearman (not Pearson) used for all correlations given small, likely non-normal samples. Confidence labels follow: STRONG N≥100 & consistent effect · MODERATE N≥30 & a single clean pass · WEAK N 10–30 or noisy · RESEARCH ONLY suggestive pattern, N<10 or high noise · INSUFFICIENT DATA N too small to say anything. Nothing in this report is labeled STRONG.

Independence caveat (restated)

Any statistic computed across the 11-strike candidate universe (Parts 12–16) has an effective independent N equal to the number of days (46), not the number of candidate rows (506–1,012). This report labels those sections accordingly and this caveat should travel with any reuse of these numbers.

Part 23 — Conceptual 2:59 PM Decision Framework (research design only, not implemented)

  1. Check data completeness (≥11 strikes/side within ATM±5, option snapshot ≤2 min stale) — else → NO TRADE.
  2. Compute the underlying 2:59 state vector (VWAP distance, momentum, POC migration, compression ratio).
  3. Compute the options 2:59 state vector (PCR, IV skew, straddle trend, call/put volume imbalance).
  4. Score Model B (options-only vote) — the only individually-validated edge found this milestone.
  5. Check historical analog depth (via the existing find_analogs/k-NN engine) — thin sample → downgrade confidence.
  6. Check underlying-vs-options divergence — if they disagree (the common case, 70% of days), weight toward the options-side per Part 10's finding, but flag CONFLICTED.
  7. If Model B says UP → CE candidate; DOWN → PE candidate. Prefer ATM-to-modestly-ITM strikes only where symbol-specific evidence supports it (SENSEX only, per Part 15) — otherwise default to ATM.
  8. Apply realistic ask-entry pricing; downgrade the opportunity score when bid-ask spread% is wide (execution-cost risk, Part 12/13).
  9. Final gate: if Model B's margin over 50% is thin AND analog N is thin AND divergence is flagged → NO TRADE. This is a mandatory output category, not a fallback of last resort — Part 16 shows blind/undirected option buying loses money on average.

This is a conceptual pipeline for future validation — no code in the production repository implements it.

Final Question — Candid Answer

Does the data support a reliable BUY CE / BUY PE / WAIT decision at 2:59 PM today?

Not yet, and it would be dishonest to say otherwise. This milestone found exactly one candidate edge worth carrying forward — an options-positioning-only vote (PCR + call/put volume imbalance + straddle change) that beats chance at 58.7% accuracy. That is a real, reproducible signal, not noise from overfitting (it's three simple, pre-specified features combined by an unweighted majority vote, not a tuned model) — but 58.7% on N=46 days is a thin edge, not a tradeable one on its own. Every attempt to strengthen it by adding more features (underlying price action, deeper strike selection, theta/IV decomposition) either added nothing or made it worse once independence and sample-size were accounted for honestly.

What would change this answer: (1) more days — each additional month of CAS-era data adds roughly 20 more symbol-days, and the effective sample here (46) is still an order of magnitude below what would let any of today's WEAK/RESEARCH-ONLY findings graduate to MODERATE or STRONG; (2) an out-of-sample test — everything in this report is a single in-sample pass, with no held-out validation; (3) resolving the SENSEX-vs-NIFTY strike-selection disagreement with more data before committing to either symbol's pattern.

Until then, the honest default at 2:59 PM is WAIT — not because nothing was found, but because what was found isn't yet strong enough to act on with real capital.
