How the engine works

The score (fixed before any Validation/Test look)

score = |delta| × expected_move_points        # linear payoff approximation
        − spread                              # ask − bid, the real round-trip cost
        − |theta| × (15 / 375)                # 15-min share of a per-trading-day theta

expected_move_points = Training-only median |realized 15-min move|
                     → NIFTY 8.85 pts, SENSEX 23.85 pts

Execution realism

Entry = ASK at 14:59 (frozen). Exit = BID at 15:00 / 15:05 / 15:10 / 15:15. Never LTP, never midpoint. MFE/MAE are computed on the bid path and reported as diagnostics only, never as an assumed executed return. Pre-cost — no brokerage/tax model exists, so none was invented.

NO-TRADE gates (all pre-registered)

Data-quality (no snapshot / stale snapshot / empty chain) → no clear edge (control abstains) → empty universe → no eligible candidate (missing quote, or spread > 5%) → top score ≤ 0. Checked in fixed order so the reason is always traceable.

Limitations that must be resolved before paper trading

  1. The gates never fire. All 46 symbol-days produced a positive top score; SPREAD_TOO_WIDE and EXPECTED_BENEFIT_NONPOSITIVE fired zero times. Trade frequency was 100% in every tier — so the engine currently has no ability to distinguish a good setup from a bad one. Recalibration is needed, but doing it now against these same results would be tuning on Test.
  2. The score structurally favors the extremes of the ATM±5 window (max-delta deep ITM, or minimum-absolute-cost deep OTM) over near-ATM strikes — a consequence of an unnormalized raw-points formula, not necessarily an economic signal.
  3. Theta units are an assumption — assumed per-trading-day, scaled ×15/375. If Dhan's convention differs, every theta-cost number is indicative only.
  4. expiry_type is NaN for most rows in the reused 11A dataset, so the expiry breakdown could not be computed. Pre-existing gap, not introduced here.
  5. Sample size — 28/10/8 symbol-days. The effective statistical unit is the symbol-day, not the 22 candidate rows per day; nothing here is a statistically strong claim.

Recommendation

C. NO — insufficient evidence; continue data collection.

Not "CONDITIONAL", because the flaw is in the option-expression logic itself (gates that never bind, a formula biased to chain extremes), not merely in the weak direction signal underneath it. Against the retention criteria, the rule is deterministic and leakage-clean but fails on economic meaningfulness: it does not beat not trading.

No option-expression rule is retained. No paper-trading agent is authorized by this milestone.
